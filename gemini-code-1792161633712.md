# 🎨 Hello World Motion Lab

A Streamlit web application that lets users customize text fonts, background themes, display modes, and continuous weather/particle motion effects.

## Files Included
- `app.py`: Main Streamlit application file.
- `requirements.txt`: Python package dependencies.
- `render.yaml`: Configuration blueprint for Render.com.
- `.gitignore`: Files ignored by Git.

## Deployment on Render.com
1. Push all files to a GitHub repository.
2. Connect the repository on Render.com as a **Web Service**.
3. Use the start command: `streamlit run app.py --server.port $PORT --server.address 0.0.0.0`
